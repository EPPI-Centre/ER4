Radio-button codes are "mutually exclusive" codes: when they share the same parent, only one can be ticked.
Thus, ticking one radio-button code will automatically un-tick any other radio-button code located at the same level.
Moreover, radio-button codes cannot be moved to a different parent, but can be converted to non-radio codes.
Existing non-radio codes cannot be transformed into radio-button codes.
